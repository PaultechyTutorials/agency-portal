## 🛠️ Built With (Tech Stack)
This project was constructed from scratch locally on a development server utilizing:
* **HTML5** - Structuring modern semantic layouts.
* **CSS3** - Responsive Grid arrays, uniform margins, smooth animations, and hover transitions.
* **JavaScript (ES6+)** - Interactivity layer controlling dynamic DOM state changes.

---

## ✨ Features Added
* 📊 **CSS Grid Architecture:** Automatically aligns items into grids on wide screens or neat stacks on mobile devices.
* 🎬 **Staggered Keyframe Animations:** Smooth cascading entry motion for core service modules when loaded.
* ☀️/🌙 **Dynamic Theme Engine:** Pure JavaScript handler that seamlessly flips the application between light and dark modes instantly.
